# 聊天室採分層 prompt 與自然回覆契約

聊天室將角色身份、Persona、語氣與硬性規則放在 system／developer 層；當輪人類訊息、共享會議記憶、引用訊息與 `#` 指定附件放在上下文層。模型的 JSON 只作為傳輸格式，前端直接呈現自然對話，不顯示固定報告欄位，必要時才追問或補充背景。

回覆長度依問題與使用者要求自適應：一般問題精簡，複雜問題可完整分段，不設固定句數或字數，也不強制使用正式報告欄位。

回覆可依內容需要使用 Markdown（例如列表、粗體、短標題或程式碼區塊），但不得固定套用模板；簡單問題應維持自然段落。
