# 聊天室附件必須明確引用

聊天室附件透過 `#` autocomplete 選取，畫面顯示人類可讀的附件標籤，傳送時使用穩定的 `file_id`。沒有 `#` 時不得把任何附件正文放入 prompt；有 `#` 時只注入被選取且 AI 可讀的附件正文，附件引用不改變 AI 回覆路由。

一則訊息可以引用多個附件；引用順序依使用者選取順序保留，重複的附件只注入一次。

送出時必須重新驗證引用的附件仍存在、可讀且對目標角色可用。若任一引用失效，該次訊息不建立 AI job，保留編輯內容並提示使用者修正；系統不得靜默省略失效附件或改用未指定的附件。

目前聊天室的 AI 可讀附件限定為 `.txt` 與 `.md`。PDF、圖片、ZIP 與其他二進位檔可保留在聊天中供下載／預覽，但不列入 `#` 可選正文；解析或 OCR 另立功能。

`#` 指定的是可使用的附件來源，不代表無上限注入整份正文。小型文字附件可注入全文；大型文字附件必須擷取與當前問題相關的段落，所有擷取內容都計入上下文預算；找不到相關內容時明確告知，不得靜默截斷或假裝已讀完整檔案。

即使訊息以自然語言提到附件，沒有 `#` 仍不得讀取或檢索附件正文；系統可提示使用者以 `#` 明確選取附件。
