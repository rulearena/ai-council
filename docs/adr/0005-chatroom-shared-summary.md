# 長聊天室採共享會議摘要

聊天室完整 transcript 永久保存，但模型 prompt 以共享會議摘要、最近訊息、引用訊息及明確 `#` 附件建立上下文。摘要在上下文接近門檻時自動更新，所有角色共用同一份摘要，不為個別角色建立不同版本。

共享摘要不產生聊天氣泡；它是會議脈絡的一部分，可在脈絡／記錄介面查看其內容、版本與更新時間。

摘要只在預估上下文接近門檻、且回覆回合進入穩定狀態時更新；`@all` 必須等目標角色完成、失敗或取消後再更新。摘要保留重要事實、已確認決策、未解問題與下一步，附件只保留引用／metadata，不把正文永久寫入摘要。完整 transcript 仍是唯一事實來源，摘要可由它重新生成。

摘要由 backend 的專用摘要任務生成，不算主持 AI 的聊天發言，使用獨立 prompt／schema，預設沿用主持 AI 的模型配置但不套用主持聊天 Persona。摘要失敗時保留上一版，暫時只使用最近訊息上下文，不阻斷聊天室。
